# 6.0 - 30 July 2026

## Upgrade notes

- You MUST upgrade to the most recent WebHare 5.9.x version AND upgrade to Postgres 17 or higher before upgrading to WebHare 6.0
  - Deal with any reported deprecation warnings. Run `wh deprecationscan` manually for a direct report after updating (The builtin report in dashboard is generated only once a week)

## Things that are nice to know

- Tollium:
  - Collapsable `<section>` element
  - Developer shortcuts:
    - ctrl+alt+shift+/ (usually '?') for help
    - ctrl+alt+shift+f to highlight current focus Tollium element
    - ctrl+alt+shift+r to restart current Tollium application
  - Use x-webhare:placeholder to have the iframe load the rabbit placeholder
  - Fix Chrome 150 drag&drop breakage by adding an extra chromium/x-drag-id drop type
  - Iframed components use the current origin instead of about:srcdoc to avoid issues with components checking Referer (eg google maps api)
- Consilio:
  - adds `foldertype=` to `<addtocatalog`. this allows you to add folders by type instead of path, avoiding errors if folders are moved or missing
  - adds customactions= to `<wrd:entitesedit>` and `<arrayedit>` to include existing actions as additional actions
- WRD:
  - Adds --ignorepayments to wrd import so partial imports can succeed
  - Adds wrd() to access schemas, avoiding the need to do non-type imports on generated files.
  - WRD 'time' types can be changed to 'integer' without migration to deal with time fields using values < 0 or values >= 24h
- Publisher:
  - The document editor now has a Metadata tab. Properties that are managed as part of workflow/versioning (ie. part of drafts and save/publish workflows) are added here.
    - Adds a "Schedule publication" dialog and schedule management in the workflow handler (documents with upcoming scheduled publishes are treated readonly; autosave/draft ordering/behaviour adjusted)
  - Use HideMetadataTab() on editdocumentapi to hide the new metadata tab
  - Adds support for TypeScript based webdesigns
  - Adds ogshareimage to webdesign simply get/set the og:image share url without having to setup opengraph plugin (backporting to WH 5.9.3)
  - Adds seofield pageheading, similar to seotitle but for overriding the H1 title
  - Allows to set global custom hyperlink plugins for WebDesignBase::ResolveHyperlink
  - Application links allow sharing deeplinks straight to the RTD
- Webdesigns:
  - All add-on modules receive a `/.wh/mod/<modulename>/public/` virtual directory that points to the `public` folder of the module. This is intended to replace both the `/tollium_todd.res/` and `/.publisher/sd/` rules.
  - allow passing specific prompt option to startSSOLogin.
  - allow setting language explicitly in setupGoogleRecaptcha call
  - getAssetBase() - tracks a codecontext-scoped base url for CDN assets
  - getModulePublicAssetBase() to get path to `/.wh/mod/<module>/public/` folder
- Debugging improvements
  - Adds `wh bridge get-locks`
  - Adds `wh auth list-oauth2-initiations` to debug oauth2 logins
  - `wh bridge` is now `wh debug`, `wh debug` is now `wh harescript-debug`
  - Expose `WorkerPool` to the debug API and register workerpools on `$wh` (allows workerpool GC and runtime inspection)
  - A new Node debugger application in WebHare allows you to connect to running nodejs processes using devtools. This also allows performance and memory profiling.

## Incompatibilities and deprecations

We have removed deprecation warnings about MAX_DATETIME. JS can properly deal with maxDateTimes in WHFS and WRD, although we'd still recommend avoiding maxDateTime (and thus it will keep requiring a @webhare/hscompat import)

- Support for Word conversion/publication has been removed.
- Support for HareScript code in the WebHare filesystem (publisher) and in published output has been removed.
  - The webserver will only run HareScript code from a module folder, not from output/ or storage/ folders
  - site:: and currentsite:: loadlib paths are no longer supported
- Linters will now generate warnings for non-erasable TypeScript syntax. We intend to fully require erasable TypeScript syntax in a future release. (ie, enums and storage specifiers in constructors will be disallowed)
- Removal/cleanup of public enums: several public enums and constants were removed or refactored (including `HTTPMethod` — use plain strings like 'GET'), and WRD/witty enums were adjusted; check your code for enum references.
- ajvformats has been upgraded to 3.0.0. This has some effects on OpenAPI specifications:
  - Formats time and date-time now require timezone, as per JSON Schema specification / RFC3339.
  - Added formats iso-time and iso-date-time that have optional timezone, they can be used for backwards compatibility.
  - Keywords formatMaximum and formatMinimum for time and date-time format now take into account timezone (both for time and for date), the previous comparison logic that ignored timezone is preserved for iso-time and iso-date-time formats.
- drops support for `<extendformeditor settingsextension= />`. you should use normal tabsextension/extendProps and enable workflow for the contenttype (workflow=true / clone: onDraft) to add the settings to the Metadata tab instead
- support for `<formsettings extendobject= />` has been removed
- managedtagedit now requires a taglibrary=
- photoalbum folders are deprecated, special handling (such as resizing images) has been removed
- remove `@webhare/frontend` standard inclusion of reset.css - you should add `import "@webhare/frontend/styling/reset.css";` yourself if you need it
- removed publisher:publisher_objectprops_extensions hook
- removed rss parser
- removes `<backendservice>` moduledefinition.xml support. use backendServices: in moduledefinition.ylm
- seotabrequireright is no longer supported
- support for polls has been removed
- support for rarely used `<customplugin>` has been removed
- tabs type=stacked support has been removed, users are recommended to switch to regular tabs or the new `<section>` element (unofficially backported to 5.9.2)
- test APIs no longer support a callback as annotation pameter, use { annotation: callback } instead
- URL parsing is closer to the standards now: &, ; and ? are no longer interchangeable but URLs must have proper ?var=1&var2=2 syntax
- webdesign->RunAsWidgetPreview will be removed
- `wh:wrd/` imports are deprecated, you should switch to `wrd()` in WH6.0 code.
